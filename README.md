# 星川达人匹配工作台（服务商版）

面向服务商的独立 GitHub Pages 站点，仅保留原星川决策工作台中的「达人匹配」板块，并将匹配池限定为三个新增达人库。

## 匹配池

1. 优质星川达人（增量达人库，994 人）
2. 潜力星川达人推荐（规则测算与分层）
3. 星图达人推荐（精选联盟激励候选，筛选后 AI 评分）

存量星川达人库、服务商自有/本机存量库及 xc-tagger 自助打标入口均已隐藏，匹配请求固定传 `local_stock: []` 且 `stock_count: 0`。

## 功能范围

- 商品信息录入与内容偏好标签
- 三池达人智能匹配、AI 相关性评分与规则分层
- 数量调整、优化筛选、重新匹配
- 分池展开、分页查看、主页与代表视频链接
- 单池导出与全量 CSV 导出
- 免登录开放访问，匹配历史保存在浏览器本机

## 访问与身份边界

- 站点免登录、免登记，打开即用；首次访问自动写入本机身份「本机用户」，无登录弹窗
- 匹配历史保存在浏览器本机（localStorage / IndexedDB），不跨设备同步；顶部历史仅展示达人匹配记录
- 未登记状态下隐藏「引用爆品库商品」入口与真实 AI 镜头生成按钮（`?demo=1` 演示模式仍可体验镜头效果）
- 三池真实匹配、AI 评分、CSV 导出等核心链路均无需登录，请求不携带任何访问令牌
- 追加 `?demo=1` 进入演示模式：使用本地预置数据，不发起真实 AI 请求

## 技术栈

React 19、TypeScript、Vite、Tailwind CSS、Framer Motion。生产构建通过 `vite-plugin-singlefile` 将主程序内联为单个 `index.html`，另保留 `xlsx.full.min.js` 作为按需加载资源。

## 本地开发

```bash
npm install
npm run dev
```

## 生产构建

```bash
npm run build
```

构建产物位于 `dist/`，可直接部署到 GitHub Pages。
